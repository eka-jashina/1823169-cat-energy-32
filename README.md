**Cat Energy** — адаптивный сайт из двух страниц (главная и каталог), созданный в рамках обучения. Проект представляет собой сайт магазина кормов для животных с адаптивной вёрсткой и минимальной интерактивностью.

## Технологии

- HTML5, BEM
- SCSS (Sass)
- JavaScript (минимум логики)
- Gulp (сборка проекта)
- SVG-спрайты
- Оптимизация изображений: использование <picture>, ретинизация
- Линтеры: ESLint, Stylelint, linthtml

## Возможности

- Резиновая вёрстка для десктопа, планшета, мобильного.
- Минимальные анимации и интерактивные элементы
- Поддержка современных браузеров Chrome b Firefox
